### Capacidades de TaskFlow Lite

| Capacidad                        | Clasificación         | Valor                                                                            |
| -------------------------------- | --------------------- | -------------------------------------------------------------------------------- |
| Registrar tareas                 | **Esencial para MVP** | Permite incorporar nuevas tareas al sistema para comenzar su seguimiento.        |
| Consultar tareas                 | **Esencial para MVP** | Permite al equipo conocer qué tareas existen y revisar su información.           |
| Actualizar tareas                | **Esencial para MVP** | Permite mantener la información de las tareas al día conforme avanza el trabajo. |
| Conservar las tareas registradas | **Esencial para MVP** | Evita perder la información y permite mantener el seguimiento de las tareas.     |
| Buscar tareas                    | **Posterior**         | Facilita localizar rápidamente una tarea cuando aumente la cantidad registrada.  |
| Filtrar tareas                   | **Posterior**         | Permite enfocar la consulta en determinados tipos o estados de tareas.           |
| Eliminar tareas                  | **Posterior**         | Permite retirar tareas que ya no necesiten permanecer en el seguimiento.         |
| Priorizar tareas                 | **Posterior**         | Ayuda al equipo a distinguir qué tareas requieren mayor atención.                |
